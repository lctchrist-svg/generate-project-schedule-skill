# 排期规则

## 工期口径

`totalWorkdays` 是服务建议书约定的板块总工期。板块内全部细项必须在这些日期内完成。细项的持续时间只用于甘特图分配，不得相加后延长板块。

## 日期规则

- 正式工作日：普通周一至周五，以及国家公布的补班日。
- 非工作日：普通周末、法定节假日和调休日。
- 提案日：板块最后一个正式工作日之后的下一个有效工作日，不计入 `totalWorkdays`。
- 后续板块：默认从上一板块提案日之后的下一个有效工作日启动；上一板块无需提案时，从其最后工作日之后的下一个有效工作日启动。
- 跟进期：默认 5 个有效工作日，仅作估算。

## 并行规则

- 默认最多 2 个细项并行。
- 每个细项的开始序号和结束序号必须位于 `1..totalWorkdays`。
- 每个正式工作日应至少覆盖一个细项，避免板块内部出现无任务空档。
- 若服务建议书只给板块级工期，可按“研究/输入 → 方案 → 深化/验证 → 整理交付”顺序分配细项。

## 颜色

- 灰色：前期准备。
- 绿色：正式工作日。
- 粉色：提案/评审日，不计正式工期。
- 黄色：按需跟进估算。
- 浅灰：周末及法定休息日。
- 浅黄：法定补班日。

## 交付前校验

- 板块正式日期数量等于 `totalWorkdays`。
- 提案日未出现在正式日期集合中。
- 无提案板块不存在提案节点。
- 细项日期没有越过板块边界。
- 正式工期合计等于各板块 `totalWorkdays` 之和。
- Excel 参数页、摘要、阶段日期与甘特图一致。
